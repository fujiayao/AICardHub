# 全局视觉简报（供后台 admin worker 参考）

> 来源：opus-h5 改版。后台用 Element Plus，以下为跨端统一约束，按 Element Plus 变量映射即可。

## 调色板
- 品牌深蓝 ink `#13294B`（标题、身份区、侧栏底色）；ink-2 `#22406E`；ink-3 `#3A5A8C`
- 主操作 `#2F6BFF`（按钮、链接、选中），按下 `#1F56E0`，浅底 `#EAF0FF`
- AI 分身青 `#0E9E98`，浅底 `#E2F5F3`（只用于 AI 相关标识：AI 头像、AI 标签、试聊、知识引用）
- 提醒 `#E08A1E`、危险 `#E5484D`、成功 `#1E9E5A`
- 背景 `#F3F5F8`、面 `#FFFFFF`、分隔线 `#E5E9EF`、正文 `#1A2433`、次级 `#5A6677`、弱化 `#8D97A5`
- 不使用绿色/金色 CTA，不使用渐变炫彩。

## 字体
系统中文字体栈：PingFang SC / HarmonyOS Sans SC / MiSans / Microsoft YaHei / Noto Sans SC / system-ui。数字 DIN Alternate / Roboto，tabular-nums。不加载任何网络字体（Google Fonts 等）。
字号阶梯 12 / 13 / 15 / 17 / 20 / 24 / 30。

## 密度
4px 间距阶梯（4/8/12/16/20/24/32/40）。卡片圆角 14，按钮/输入 10，标签 6。普通卡片用 1px 描边，只有浮起元素用阴影。触控目标 ≥44px（H5），后台行高 ≥40px。

## 表单与状态
- 可见 label，错误紧邻字段，帮助文案在下方；必填用文案说明，不只靠颜色。
- 每个列表/详情都有 加载（骨架）/ 空（说明 + 下一步）/ 错误（原因 + 重试）三态。
- 未接入契约的功能：禁用态 + 「待接口支持」说明，不做假开关。

## 无照片 / 无手机号
这是主状态，不是兜底：用姓名首字徽章（深蓝底、白字、圆角方形）+ 姓名 + 职务 + 单位层级呈现；不放大号通用人像剪影，不用公司 logo 当人像。无手机号时不渲染拨号入口（不是禁用按钮，是不出现）。

## 长单位名
公司/单位名可达 20 个汉字：允许换行（最多 2–3 行），容器 `min-width:0`、`overflow-wrap:anywhere`，不截断语义，不与相邻元素重叠。

## 知识引用
只展示公开标识映射后的可读标签（标题/分类）；私有、内部或无法识别的路径一律显示通用标签「知识资料」，绝不显示文件系统路径。
