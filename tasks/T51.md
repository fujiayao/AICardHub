## 目标

编写 Dockerfile、生产 docker-compose、nginx 配置和备份脚本。

## 允许修改

- `server/Dockerfile`
- `deploy/`
- `apps/*/Dockerfile 或构建脚本`

## 不得修改

apps/（生成目录除外）、server/tests/acceptance/、scripts/、tasks/BOARD.md；server/app/core/ 除非任务卡明确允许

## 验收标准

1. 服务：nginx、api（uvicorn 2 workers）、scheduler（1 个）、mysql；数据卷 /data/kb、/data/uploads、mysql-data
2. nginx：/ 与 /staff → H5 静态，/admin → 后台静态，/api → api，/files → 上传目录，/c/ → api；对话相关路径 `proxy_buffering off; proxy_read_timeout 120s;`；按 IP limit_req；gzip
3. api 入口脚本执行 `alembic upgrade head` 后启动
4. `deploy/backup.sh`：MySQL 每日备份 + kb 目录打包，保留 14 天
5. `deploy/README.md`：从零部署步骤（含 HTTPS 证书放置位置）
6. 本机 `docker compose up` 后完整流程可用，SSE 流式在 nginx 后仍逐字输出（附录屏或说明）

## 必须通过

本机生产模式启动并跑通 e2e
