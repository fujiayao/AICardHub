# 任务 T22：客户、线索与统计接口

| 项 | 内容 |
|---|---|
| 角色 | 后端智能体 |
| 阶段 | 阶段 1：功能并行开发 |
| 参考工作量 | 2 天（按人天估算，智能体通常更快） |
| 开工条件 | T18（站内信与定时任务） 已合并到 main |
| 依据 | 开发方案 §5.2 客户、§9.2 |
| 接口 | me_visitor_*、me_lead_*、me_stats |
| 数据库 | — |

## 目标

实现员工端访客列表与详情、线索状态流转、个人统计。

## 允许修改

- `server/app/modules/visitor/`
- `server/app/modules/lead/`
- `server/app/modules/stats/`
- `server/tests/`

## 不得修改

apps/（生成目录除外）、server/tests/acceptance/、scripts/、tasks/BOARD.md；server/app/core/ 除非任务卡明确允许

## 验收标准

1. `GET /me/visitors`（筛选：来源、意向、是否留资；分页）、`GET /me/visitors/{id}`（访问轨迹、会话列表、最近会话消息、AI 摘要）
2. `GET /me/leads`（按状态筛选）、`PATCH /me/leads/{id}`（状态、备注；打开详情时相关站内信标为已读）
3. 列表手机号脱敏，详情完整
4. `GET /me/stats?range=7d`：今日访客/对话/新线索、较昨日、近 7 天访客
5. 所有查询只用 current_staff.id；每个接口都有越权测试；验收测试 ② ③ 通过

## 必须通过

scripts/check.sh 全部通过

## 交付

- 代码 + 测试 + 交付报告
- 交付报告写入 `tasks/reports/T22.md`（格式见 AGENTS.md），提交到任务分支 `feat/T22-<英文短名>`
- 回复：“T22 已交付，分支 feat/T22-…，报告 tasks/reports/T22.md”

## 契约提醒

接口字段已在 T10 冻结。实现时删除对应接口的 `NotImplementedError` 占位，不改请求/响应字段；确需修改先写 ADR 草稿并停下等待确认。
