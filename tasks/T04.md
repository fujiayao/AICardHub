## 目标

把 pure-admin-thin 模板改造成本项目后台工程：静态路由、去掉刷新 token、接口适配层。

## 允许修改

- `apps/admin/`

## 不得修改

server/、contracts/、apps/*/src/api/generated/（只能由 gen-api.sh 生成）、scripts/、tasks/BOARD.md

## 验收标准

1. 关闭动态路由（不再请求 getAsyncRoutes），菜单改为静态路由，仅包含 C1–C10 的占位页面
2. 去掉 refresh token 逻辑；token 过期或 401 时跳登录页
3. 新增 `src/api/adapters/`，把后端“直接返回数据 / {code,message} 错误”转换为模板组件需要的结构
4. 删除模板自带 mock 登录和示例页面；站点标题改为“数科名片管理后台”
5. 登录页暂时调用一个本地 mock，T37 时接通真实接口

## 必须通过

`pnpm lint`、`pnpm typecheck`、`pnpm build` 通过

- 代码 + 测试 + 交付报告
