# 任务 T21：AI 助手、个人知识与纠错接口

| 项 | 内容 |
|---|---|
| 角色 | 后端智能体 |
| 阶段 | 阶段 1：功能并行开发 |
| 参考工作量 | 2.5 天（按人天估算，智能体通常更快） |
| 开工条件 | T15（System Prompt 组装与知识路由）、T19（员工、企业信息与 AI 模板管理） 已合并到 main |
| 依据 | 开发方案 §4.4、§6.6、§9.2 |
| 接口 | me_assistant_*、me_note_*、me_kb_import、me_correction_*、me_issue_create |
| 数据库 | correction |

## 目标

实现员工端 AI 助手配置、AI 润色、个人知识增删改、文档导入、纠错记录。

## 允许修改

- `server/app/modules/assistant/`
- `server/tests/`

## 不得修改

apps/（生成目录除外）、server/tests/acceptance/、scripts/、tasks/BOARD.md；server/app/core/ 除非任务卡明确允许

## 验收标准

1. `GET/PUT /me/assistant`、`GET /me/assistant/templates`（已替换变量的预览）、`POST /me/assistant/polish`（只改表达，不新增事实）
2. 个人知识 `GET/POST /me/kb/notes`、`GET/PUT/DELETE /me/kb/notes/{file_id}`：保存为 kb/cards/{code}/notes/{slug}.md 并写 frontmatter
3. `POST /me/kb/import`：PDF（pymupdf）、Word（python-docx）提取文本 → LLM 整理为 1–N 篇草稿返回，不直接入库；单文件 ≤ 20MB；原文件不保存
4. 纠错 `GET/POST/DELETE /me/corrections`：同步写 corrections.md；来源 test / visitor_chat / manual
5. `POST /me/issues`：员工把问题提交给管理员
6. 验收测试 ② 中知识与纠错部分、⑦ 通过

## 必须通过

scripts/check.sh 全部通过

## 交付

- 代码 + 测试 + 交付报告
- 交付报告写入 `tasks/reports/T21.md`（格式见 AGENTS.md），提交到任务分支 `feat/T21-<英文短名>`
- 回复：“T21 已交付，分支 feat/T21-…，报告 tasks/reports/T21.md”

## 契约提醒

接口字段已在 T10 冻结。实现时删除对应接口的 `NotImplementedError` 占位，不改请求/响应字段；确需修改先写 ADR 草稿并停下等待确认。
