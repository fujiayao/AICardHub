## 验收标准

1. WSL2、Docker Desktop、Git、Node 22（≥22.23）、pnpm、uv、Codex CLI、magpie 都可在 WSL2 中运行
2. 运行 `bash repo-init/bootstrap.sh ~/work/shuke-ai-card` 成功：仓库已 git init 并有首次提交，三个 worktree 已创建
3. `kb-test/` 放入你的测试知识库（Markdown 文件）
4. `deploy/.env` 从 `.env.example` 复制并填入中转 API 地址和 Key（只在本机，不提交）
5. magpie 中为三个 worktree 文件夹配置好模型（本计划 §4）
