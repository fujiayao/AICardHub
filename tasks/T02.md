## 目标

搭建 FastAPI 后端骨架：配置、数据库、错误处理、鉴权工具、日志、测试框架、OpenAPI 导出。

## 允许修改

- `server/`

## 不得修改

apps/（生成目录除外）、server/tests/acceptance/、scripts/、tasks/BOARD.md；server/app/core/ 除非任务卡明确允许

## 验收标准

1. `uv` 项目，依赖按工程框架方案 §3.2，`uv.lock` 锁定；FastAPI 写精确版本
2. `app/core/`：config（pydantic-settings）、db（异步引擎 + Session 工厂 + `class Base(DeclarativeBase)`）、errors（AppError + 错误码注册 + 全局处理器，输出 `{code,message,detail}`）、security（bcrypt、JWT）、deps（get_db 等占位）、pagination（Page[T]）、logging（loguru + 请求 ID 中间件）
3. `app/main.py` 使用 lifespan；`app/modules/__init__.py` 统一注册路由列表
4. `GET /api/v1/health` 返回 `{"status":"ok"}`，并检查数据库连通
5. `python -m app.export_openapi` 不启动服务即可输出 OpenAPI JSON；所有路由必须有 operation_id（启动时校验，缺失直接报错）
6. Alembic 已初始化（异步模板），`alembic heads` 只有一个
7. pytest：使用测试库，每个测试独立事务回滚；提供 `client`（httpx.AsyncClient）夹具
8. ruff（含 ASYNC、BLE、S、B、UP 规则）和 mypy 严格模式配置完成，当前代码零告警

## 必须通过

`uv run ruff check`、`uv run mypy app`、`uv run pytest` 全部通过
