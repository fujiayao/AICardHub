## 目标

实现 kb/ 目录的读写、加锁、本地 Git 历史，以及 frontmatter 解析、校验、Token 估算和索引缓存。

## 允许修改

- `server/app/kb/store.py`
- `server/app/kb/loader.py`
- `server/app/modules/kb_index/（kb_file 表）`
- `server/tests/`

## 不得修改

apps/（生成目录除外）、server/tests/acceptance/、scripts/、tasks/BOARD.md；server/app/core/ 除非任务卡明确允许

## 验收标准

1. `store`：读、写、删、列出、历史、回滚；写入使用 filelock（按名片或公司目录加锁），写入后在 kb 目录执行 git commit（线程池中执行）
2. `loader`：解析 frontmatter（缺省 id 用文件名、缺省 title 取首个一级标题）；`description` 缺失时调用 LLMClient 生成（接口注入，测试用 FakeLLM）
3. 校验失败的文件不进入索引并记录错误原因；索引按 sha1 失效
4. Token 估算（tiktoken o200k_base，失败时按中文字符×1.0+英文单词×1.3）
5. 用 `kb-test/` 作为公司知识跑单元测试：能全部加载、统计总 Token
6. `kb/` 包不 import fastapi；覆盖率 ≥ 80%

## 必须通过

scripts/check.sh 全部通过
