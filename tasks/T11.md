# 任务 T11：鉴权：员工与管理员登录

| 项 | 内容 |
|---|---|
| 角色 | 后端智能体 |
| 阶段 | 阶段 1：功能并行开发 |
| 参考工作量 | 1 天（按人天估算，智能体通常更快） |
| 开工条件 | T10（全量接口契约（契约冻结，把关点 G2）） 已合并到 main |
| 依据 | 开发方案 §3、§9.2–9.3；工程框架方案 §6.5 |
| 接口 | auth_login、auth_change_password、admin_auth_login |
| 数据库 | employee 增加登录相关字段（如 T06 未包含） |

## 目标

实现员工手机号+密码登录、首次改密、锁定，以及管理员登录和权限依赖。

## 允许修改

- `server/app/modules/auth/`
- `server/app/core/deps.py（仅补充 get_current_staff / get_current_admin）`
- `server/tests/`

## 不得修改

apps/（生成目录除外）、server/tests/acceptance/、scripts/、tasks/BOARD.md；server/app/core/ 除非任务卡明确允许

## 验收标准

1. `POST /auth/login`（`auth_login`）、`POST /auth/change-password`（`auth_change_password`）、`POST /admin/auth/login`（`admin_auth_login`）
2. 员工 token 30 天，管理员 12 小时；token 含 role；停用员工的 token 立即失效（校验 status）
3. 连续 5 次错误锁定 15 分钟，错误信息带剩余次数（错误码 AUTH_INVALID、AUTH_LOCKED）
4. `python -m app.cli create-admin` 命令创建管理员账号（交互输入密码）
5. 验收测试 ① 通过

## 必须通过

scripts/check.sh 全部通过

## 交付

- 代码 + 测试 + 交付报告
- 交付报告写入 `tasks/reports/T11.md`（格式见 AGENTS.md），提交到任务分支 `feat/T11-<英文短名>`
- 回复：“T11 已交付，分支 feat/T11-…，报告 tasks/reports/T11.md”

## 契约提醒
