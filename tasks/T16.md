# 任务 T16：对话服务与 SSE

| 项 | 内容 |
|---|---|
| 角色 | 后端智能体 |
| 阶段 | 阶段 1：功能并行开发 |
| 参考工作量 | 2.5 天（按人天估算，智能体通常更快） |
| 开工条件 | T15（System Prompt 组装与知识路由） 已合并到 main |
| 依据 | 开发方案 §4.7、§9.1、§9.4；工程框架方案 §7.1 |
| 接口 | chat_*、test_chat_* |
| 数据库 | chat_session、chat_message、issue_pool |

## 目标

实现会话、消息、SSE 流式输出、NOKB 标记过滤、调试对话接口。

## 允许修改

- `server/app/modules/chat/`
- `server/app/modules/issue/（写入问题池部分）`
- `server/tests/`

## 不得修改

apps/（生成目录除外）、server/tests/acceptance/、scripts/、tasks/BOARD.md；server/app/core/ 除非任务卡明确允许

## 验收标准

1. 接口：`POST /public/chat/sessions`（`chat_session_create`）、`POST /public/chat/sessions/{id}/messages`（`chat_message_stream`，SSE）、`GET .../messages`（`chat_message_list`）、`POST /public/messages/{id}/feedback`（`chat_feedback`）、`POST /me/test-chat/sessions` 与 `.../messages`（`test_chat_*`）
2. SSE 事件：delta、lead_prompt、done（含 message_id、kb_refs、nokb、model）、error，格式按开发方案 §9.4
3. 生成器内自行 `async with SessionLocal()`；客户端断开即停止调用模型，已生成内容落库
4. `stream_filter.py`：保留尾部 8 字符缓冲过滤 `<<NOKB>>`，单测覆盖“标记被拆成两段/三段”
5. 历史携带最近 6 轮；限流与敏感词在调用模型前执行
6. 点踩与 NOKB 写入 issue_pool（同问题累加 count）
7. 验收测试 ③ ⑥ ⑩ 通过

## 必须通过

scripts/check.sh 全部通过

## 交付

- 代码 + 测试 + 交付报告
- 交付报告写入 `tasks/reports/T16.md`（格式见 AGENTS.md），提交到任务分支 `feat/T16-<英文短名>`
- 回复：“T16 已交付，分支 feat/T16-…，报告 tasks/reports/T16.md”
