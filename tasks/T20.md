| 项 | 内容 |

| 角色 | 后端智能体 |

| 接口 | me_card_*、card_vcard |
| 数据库 | — |

## 目标

实现员工编辑名片、职业照上传、二维码、海报、vCard。

## 允许修改

- `server/app/modules/card/`
- `server/app/integrations/storage/`
- `server/tests/`

## 不得修改

apps/（生成目录除外）、server/tests/acceptance/、scripts/、tasks/BOARD.md；server/app/core/ 除非任务卡明确允许

## 验收标准

1. `GET/PUT /me/card`（`me_card_get`、`me_card_update`），锁定字段（部门、公司）不可由员工修改
2. `POST /me/card/photo`：校验类型与大小，Pillow 生成名片图（宽 750）与对话背景图，文件名 UUID
3. 微信二维码上传同上
4. `GET /me/card/share`：返回二维码图、海报图、短链文案；海报按原型 B4 版式生成并缓存，名片变更后失效
5. `GET /public/cards/{code}/vcard`：vCard 3.0，UTF-8，含职业照缩略图
6. 图片处理在线程池执行

## 必须通过

scripts/check.sh 全部通过

## 交付

- 代码 + 测试 + 交付报告
- 交付报告写入 `tasks/reports/T20.md`（格式见 AGENTS.md），提交到任务分支 `feat/T20-<英文短名>`
- 回复：“T20 已交付，分支 feat/T20-…，报告 tasks/reports/T20.md”
