## NFC-00：原型与范围验证

- 角色：集成负责人 + Android 开发；前置：确定 ADR-006 交付范围。
- 允许：独立原型目录（开工时指定）、`tasks/reports/nfc/`；不接触生产服务。
- 内容：冻结 `ndef-emulator` 参考提交和许可证，模拟真实可达的合成名片短链，验证安卓到安卓及 iPhone；确认构建依赖版本与包名。
- 交付：可安装原型 APK、构建步骤、设备/系统/方向/读取与打开结果；不能只提交 README 截图。
- 门槛：优先验证目标平台读取 URI 链路。没有真机时允许继续形成软件候选，射频门槛保持待测；iPhone 发卡不在本期范围。

## NFC-01：轻量链接接口与短链回归

- 角色：唯一后端/契约所有者；依赖 NFC-00 的 URL 约束。
- 拟允许：`server/app/modules/workspace/{router.py,schemas.py,media_service.py}`、新增 `share_link_service.py`（若必要）、对应 unit/API 测试；OpenAPI 由命令生成并由集成者接收。
- 内容：新增 `GET /me/card/share-link`、operation_id `me_card_share_link`，复用来源与活动校验，抽取链接构造；302 明确 no-store。
- 验收：不渲染图片、不依赖字体；本人权限、停用、活动失效、根路径/子路径、来源参数、旧分享兼容；无迁移。
- 契约交付：响应 `{short_url,source,campaign_id}`、错误规范、更新 OpenAPI 哈希。未完成前 H5 不手写 API 客户端。

## NFC-02：员工 H5 与平台适配

- 角色：H5 开发；依赖 NFC-01 冻结契约、NFC-03 冻结 App Link 路径与参数。
- 拟允许：`apps/h5/src/pages/staff/card/{index.vue,share.vue}`、新 `apps/h5/src/pages/share/nfc.vue`、`src/platform/`、必要的分享组件及测试、路径工具；生成客户端仅按已有生成流程更新。
- 内容：新增 NFC 面板、安卓助手入口/iPhone 说明/微信说明、复制配置链接与普通分享分开；活动切换保持一致；失效活动普通名片恢复入口。
- 验收：普通浏览器不伪报硬件状态，iPhone 无空开关，二维码 s=qr/普通链接 s=link/NFC s=nfc；360–430px 可用、390×844 截图；访客无额外登录或下载要求。

## NFC-03：安卓原生分享助手

- 角色：Android 开发；依赖 NFC-00、NFC-01；只在 ADR 确认后新增 Android 构建链。
- 拟允许：`apps/nfc-android/`、客户端说明和对应报告；不更换 H5 技术栈。
- 内容：接收并校验公开链接、预览确认、NFC/HCE 检测、原生启停、5 分钟到期、前台/锁屏控制、Type 4 URI 模拟、APDU 会话一致性与错误响应。
- 验收：过程退出、重启进程和过期后不再发送；不含员工 token；其他 HCE 冲突提示明确；设备读成功不冒充网页访问；超长 URL 不截断。
- 发布输入：固定包名、签名证书指纹、发布 APK、SHA-256、依赖许可证、目标 SDK 和构建版本。

## NFC-05：联合验收与受控试点

- 角色：QA/集成负责人；依赖 NFC-01～04。
- 允许：新增测试、`tasks/reports/nfc/`；不得削弱现有验收断言。
- 输出：自动检查结果、设备矩阵、每组合 20 次试验明细、屏幕/系统/钱包/网络状态、APK 与契约哈希、截图、失败及恢复步骤。
- 口径：目标为已列支持组合至少 19/20 成功，未测机型不标支持。二维码仅通过分享可用性验收，不通过 NFC 碰触验收。
- 统计核查：短链不重复创建 visit；二维码和 NFC 来源分开；匿名初始化、对话归属、显式留资、停用名片继续正确。
- 发布门槛：实现检查、真机、域名和旧站回归均有证据；原计划灰度要求不因本功能而省略。

## NFC-06：安卓贴纸读写与采购准备

- 由 NFC-03 同一安卓所有者顺序实现，避免多人改 Manifest、Gradle 和 NFC 服务。
- 支持标准 NDEF URI 写入、覆盖前确认、实际容量检查、写后回读校验、模式互斥和主动读取；首版不提供永久锁定或原始扇区/UID 复制。
- 长期贴纸默认 `s=nfc` 且无活动 e；支持采购 NTAG213/215/216 样品，按实际字节和贴附材质测试。
- NFC-05 增加写入→回读、贴纸→安卓/iPhone 两组验收；采购到货前只记录待测，不宣称完成。
- 具体规格及验收见 [贴纸写入与采购验收](nfc/贴纸写入与采购验收.md)。
