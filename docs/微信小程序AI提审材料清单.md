# AICardHub 微信小程序 AI 提审材料清单

核对日期：2026-11-18（北京时间）。以下以微信公开文档为依据，账号提交页面和实际审核结果为准。

## 1. AI 问答类目：官方列明的资质

拟选类目：非个人主体「深度合成 → AI问答」。AICardHub 提供的是商务名片 AI 问答，不是情感陪伴；通过 `web-view` 展示同样属于实际服务范围。

| 实际技术来源 | 官方列明要提交的资质 |
|---|---|
| 自研 | 小程序主体的《互联网信息服务算法备案》，算法类型为**生成合成类**。自行开发名片、提示词和知识库，不等于第三方问答生成技术变成自研。 |
| 第三方（本项目优先按此准备） | **技术主体的《互联网信息服务算法备案》**，算法类型为**生成合成类（深度合成）**；以及**小程序主体与技术主体的合作协议**，协议包含**算法名称、算法应用场景、备案编号**中的至少一项。建议三项都写明，以便证明服务与备案一致。 |

官方依据：[小程序服务类目与资质要求 → 深度合成](https://developers.weixin.qq.com/miniprogram/product/material/#深度合成)。微信还为实际接入 [Extend.AI](https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloud/guide/extensions/extend/ai.html) 的项目说明了「在用证明」路径。它不是所有 API 供应商通用的证明，也不意味着为了拿证明必须更换供应商。

### 可以直接发给当前 AI 服务商的询问

> 我们拟在企业主体的微信小程序「AICardHub / 数科 AI 智能名片」中提供商务名片问答，请确认你方实际提供的模型与算法服务，能否用于微信小程序「深度合成—AI问答」类目审核。请提供技术主体全称、可提交的生成合成类算法备案凭证（算法名称、备案编号、覆盖的应用场景），并确认是否可以由我方小程序主体与该技术主体签署合作协议，明确覆盖这个小程序的文本问答。若你方为中转、代理或聚合平台，请说明实际技术主体、模型对应关系及可出具的授权/合作材料；请分别说明主用及备用模型是否都在材料覆盖范围内。

**先核对在生产实际启用的主用和备用模型。** 购买订单、充值记录、API Key、模型列表截图、平台宣传或仅有中转商营业执照，不是上述备案和合作协议的替代品。公开类目页未对所有回退路由逐一列出提交办法，因此不要假定一份证明自动覆盖不同提供方。若证明仅覆盖一部分路由，提审版本应使用审核材料覆盖的实际服务；如中转方仅能提供授权链，先通过该账号的类目审核入口确认可否采用，不保证认可。不要将密钥、服务器口令、真实访客聊天或手机号放入材料。

## 2. 同时备好：提审与演示资料

下面是交付准备项，不等同于每项都是「AI 问答」类目的必传附件：

- **平台基础资料**：企业主体及认证情况、正式 AppID、小程序备案、业务域名及其 ICP 备案、HTTPS 证书和业务域名校验文件。业务域名的 ICP 备案和小程序自身备案是两件不同的事。参见[业务域名](https://developers.weixin.qq.com/miniprogram/dev/framework/ability/domain.html)、[小程序备案指引](https://developers.weixin.qq.com/miniprogram/product/record/record_guidelines.html)。
- **服务说明**：写明「访客查看公开商务名片 → 主动打开 AI 助手 → 了解业务/合作 → 自愿留资」。助手明确不是员工本人，不承诺报价、合同或交付，不读出内部资料。AI 生成内容显著标注；页面标注不能代替备案材料。
- **用户隐私保护指引及网页隐私说明**：如实列业务处理的信息和用途，包括员工登录、访客问答、主动留资字段、上传功能和实际第三方服务共享；按实情说明保存期限、删除或投诉渠道。留资需主动提交和同意，不因查看名片而必须提供个人信息。对照[隐私保护指引](https://developers.weixin.qq.com/miniprogram/dev/framework/user-privacy/miniprogram-intro.html)。
- **审核演示路径**：一张允许公开的审核名片和一个权限受限的审核员工账号，通过审核后台专用入口填写，不使用管理员账号。准备名片首屏、AI 入口、生成标注、隐私告知、员工登录和首次改密的截图或录屏。实际提审时按后台要求填写。
- **内部上线核查**：使用已获准公开的员工信息、肖像和企业资料；用无敏感信息的样例验证角色说明、公开资料边界、错误提示和留资同意。模型、数据流向、协议和隐私说明须与提审版本一致。

## 3. 当前缺口与决策

- **可以先开发**：原生入口/转发、入参校验、H5 衔接、生成标注和本地测试不需要正式资质。
- **等 AppID 与域名**：业务域名校验、小程序码出图、iOS/安卓真机、微信体验版、审核入口操作。
- **等技术方材料**：若当前服务商拿不出对应资料，优先确认可提供材料的技术服务，再让你决定是否更换路由。若决定先上无 AI 名片版，应另做发布配置与权限验证：从小程序入口和可达页面实际不可访问问答，不能只藏一个按钮，也不能提审后偷偷开启。
