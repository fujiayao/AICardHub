# ADR-007 微信小程序混合适配

日期：2026-11-18。状态：混合适配开发已获批准，真实 AppID、域名和生产发布待办。

- 同一小程序使用原生入口、名片落地和转发页。访客先看公开名片，再打开独立 AI 对话；员工固定入口复用已有登录、首次改密及工作台。管理后台仍为 Web。
- 小程序码和转发路径仅传公开名片码、来源与可选活动号，不传 H5 完整地址、问句、会话 ID 或身份令牌。来源沿用现有统计类型；扫码用 `qr`、转发用 `link`，不改已发出的普通二维码、NFC 和短链。
- 推翻旧计划中把微信登录 token 拼入网页 URL 的建议。首版不做微信登录或身份绑定，访客匿名，员工用原账号。分享不依赖 WebView `postMessage` 的送达顺序。
- 不新增服务、数据库、模型路由或依赖。`apps/miniprogram/` 与 H5 同步交付，部署到测试环境后才能验 H5 桥接。旧 H5 暂未包含桥接时，访客可用原生页面菜单分享，员工的小程序转发按钮需要新版 H5。
- AppID 和真实 HTTPS 业务域名到位后才制作小程序码、验证开发者工具配置和 iOS/安卓真机。AI 发布必须核对实际服务及审核资质；无 AI 版本是单独发布范围，不用前端隐藏按钮代替访问控制。
