# ADR-005 原生部署与完整数据迁移

状态：负责人2026-11-15明确授权部署、完整业务数据迁移，指定域名路径`https://haiwex.com/aicardhub/`，不使用Docker。

## 范围

应用服务器CentOS Stream 9、4CPU/约4GB内存，已有haiwex.com网站与其他代理服务。新增应用独立账号、目录、MySQL库、loopback API与单独scheduler，复用现有Nginx的TLS虚拟主机，通过限定`/aicardhub/`的location接入。不能取代现有网站根路径或重复占用443。

前端H5、员工端、后台、API、SSE、短链、图片、vCard、二维码及海报的地址均需兼容子路径。本地开发默认路径保持原样。数据库已有`/files/`资产路径不批量重写，由请求/展示适配处理。

部署模板由Codex CLI经Magpie的`workbuddy/deepseek-v4.1-flash`路由生成并记录实际工具回执；关键方案由GPT-6.1-Sol复核。独立的路径/兼容性补丁由有明确文件范围的Codex子代理完成，执行来源如实区分。

## 数据迁移

备份并迁移本产品MySQL业务库、员工与后台账号密码哈希、名片、企业、会话、线索、上传图片及本产品本地知识资料与其版本历史。保留私有/未批准/已撤销状态，迁移不构成公开。不会复制外部知识库服务器SQLite、其他项目笔记或开发凭据。

新环境使用独立数据库凭据、轮换JWT签名密钥，并对依赖旧JWT派生密钥的模型运行配置进行受控重加密。明文迁移材料仅在权限受限、Git忽略的本地连接目录和目标私有迁移目录中处理，不发给模型、不输出、不放静态目录。导入前后核对表计数、文件SHA-256及运行功能。保持本地原数据和目标变更前配置备份。

## 知识库边界

负责人提供的服务器知识库指南描述开发智能体MCP，其远程项目及生产只读身份尚未确定。已核实通道健康与MCP初始化/tools列表，不将示例项目或开发agent凭据当作已完成产品接入。上线候选保留当前产品自身KnowledgeStore，不因远程开发库不可用而失去知识功能。远程产品接入需后续明确身份与项目授权，并独立验证，不伪称已接通。

## 本轮事件与恢复

目标服务器已备份Nginx配置，并通过dnf安装Python3.12/MySQL8/Git；依赖事务同时更新OpenSSL。随后SSH新连接在banner前断开，根因尚需云控制台的sshd日志确认。主线已停止重复登录并请求用户检查，不经其他现有服务绕过SSH执行。域名HTTPS现有根页面仍返回200。

在SSH恢复前可以完成打包、子路径改造、静态验证和本地验收；不能宣称服务器导入或上线完成。公开切换需Nginx配置校验、原站与应用功能回归、真实模型流式验证及迁移核对。
