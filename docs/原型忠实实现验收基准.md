# 原型忠实实现验收基准

负责人本轮明确：直接以 `claude/数科AI智能名片_H5原型.html` 的界面与交互为基础，改造成真实产品。此决定取代上一轮自由商务改版的视觉选择。

## 规则

- 以该原型的18个页面、状态、CSS、组件层次为直接基准；将演示数据替换为接口字段、演示点击替换为真实路由和操作。
- 不移植原型演示器的侧边导航、规格说明、手机硬件外框与伪系统状态栏；这些不是业务界面。业务区域布局和视觉需忠实保留。
- 已批准的留资同意、身份隔离与改密安全规则继续生效；原型的手机号自动建线索不恢复。
- 没有真实头像时可复用原型的匿名职业插画作为明确占位，不生成或冒充高管真人照片。没有电话、微信时相应操作隐藏或按原型降级。
- 原型中有但接口缺少的字段，应补后端真实字段或明确缺失，不能擅自删功能区、贴假数值或更换为不相关布局。
- 前端实现由Magpie路由的Claude Code Opus5.5承担。Vue与UI技能只辅助实现、无障碍和检查，不覆盖原型设计。

## 活动入口

已复现：匿名访问`/activities`被跳转到`/login`，登录固定返回`/dashboard`，丢失原目标。活动菜单和CRUD在当前运行版本实际存在，但深链登录体验有缺陷。修复安全站内返回路径，并验证菜单可见、活动创建入口和报告导航。
