# 48 小时冲刺：压缩的是范围，不是验收真实性

提案基准日：2026-11-14（Asia/Shanghai）。若当日开工，24h目标约为11月15日、48h约为11月16日；实际由环境与资料就绪时间起算。所有估时是目标窗口，不是保证。

## 1. 建议试点范围（需负责人确认）

### 必做闭环

管理员创建/停用员工和名片 → 访客扫码/短链打开 A1/A4 → A2 获准知识问答与失败处理 → 自愿留资 A3 → 线索保存并归属正确员工 → 员工登录查看本人线索 → 管理员查看基础记录。附二维码/固定短链，NFC 只是该短链的真实手机入口测试。

保留：权限、脱敏、未知拒答/报价转人工、资料版本、基本站内未读提醒（无调度器复杂催办）、模型限流/超时/费用上限、备份/回滚、真实环境构建。

建议首批 3–10 张名片、1条业务线、小批获准公开文档；不得用“10人灰度”代替原计划要求的一周观察。没有获准知识时只能做合成内容演示，不能对外提供真实业务AI回答。

### 48h 可延期或手动代替（不得偷偷标完成）

B6–B9 全套个人知识/Word/PDF导入/纠错历史/调试工作台；知识版本编辑回滚 UI；Excel 批量员工导入；问题池；复杂统计图表；自动催办定时器；海报多模板；NFC 库存/批量发卡 UI；完整 C1–C10 与18页精细打磨。保留后续原任务卡，不删除。

若这些均不允许延期，应承认 1–2天不足，不承诺全量一期上线。

## 4. 发布硬门槛（实测记录而非承诺）

1. 锁文件安装、静态检查、类型检查、前后端构建、迁移到空MySQL8及升级测试均通过。
2. 业务E2E：公开名片、停用名片、登录/首次改密、自愿留资、本人线索、管理员授权、错误/空数据/超时状态。
3. 越权：员工A不能读/写员工B的名片私有数据、线索、会话、附件；用真实另一个token测404/方案允许的拒绝。跨访客会话也隔离。
4. 上传/下载路径、Markdown/XSS、提示注入、凭据泄露、公开资料范围、错误日志脱敏通过；产品输出只能引用实际允许资料。
5. FakeLLM用于自动测试；另开手动真实GPT/DeepSeek评测并分开记录。正式知识正确率≥90%、报价类拒答100%、无关请求拉回≥95%沿用原计划，记录题集版本、分母和两模型各自结果；没跑就标未验证。
6. 并发：分别说明访问、SSE长连接、上游模型请求；50并发目标不下调为已通过。4G首页≤1.5s需实测并注明设备/网络；没有对应实测只能标未验证。
7. 真机：手机浏览器/微信内短链、NFC、二维码、保存通讯录的提示/降级、SSE断线。桌面模拟截图不能代替真机。
8. 生产：域名HTTPS、持久卷、生产Key隔离、非默认密码、数据库不公开、备份+实际恢复、版本回滚、健康与成本告警、公开发布条件核验。
9. 主人书面确认试点范围、公司资料和个人信息展示范围、Go/No-Go。一周灰度验收在后续真实时间完成。

上线条件属于独立核验项，原方案“先不考虑备案”不能视为已满足合规。此文件不替代当地部署/数据处理的专业核验。

## 5. 触发止损

- T+4h样板链路仍未通：停止后台/附加页面，先通一条链路。
- T+12h权限/知识权限仍不稳：不开放AI或私人数据，缩成受控演示；不以更大模型代替修权限。
- T+24h主链路未通过：延后发布，先修阻断，不追48h数字。
- 正式公开资料/服务器未到位：交付可部署候选和验证报告，不宣称上线。
- 供应商不稳定：降并发、缩短上下文、任务切块、一次切换到已验证备用；不无限重试。
