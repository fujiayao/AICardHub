# 数科 AI 智能名片 · AICardHub

面向企业员工的AI名片：访客打开名片、交流与自愿留资；员工维护名片、助手与线索；管理员维护员工、公司和公开知识。

## NFC 使用教程与注意事项

HTTPS 服务已发布，安卓助手版本为 **1.0.0**。安卓手机可发送和接收 NFC 名片、写入贴纸；iPhone 作为接收方。接收者无需安装助手。手机碰触和贴纸读写效果以实际机型验收为准。

### 首次安装安卓助手

1. 助手要求 Android 8.0 及以上。在安卓 Chrome 或系统浏览器打开上方安装包地址，下载 APK。按手机提示，为当前浏览器允许本次安装；安装完成后可关闭该安装权限。
2. 如果装过旧的 `0.1.0-candidate` 测试包，先卸载旧包，再安装 1.0.0。两个包的签名不同，不能覆盖安装。之后的正式升级需沿用同一发布签名。
3. 打开系统 NFC 开关，联网登录员工端，进入“发送名片 → 手机 NFC”。仅“添加到桌面”不会获得 NFC 能力，发送和写贴纸需要原生助手。
4. 点“打开 NFC 助手”，核对姓名、公司及完整短链后再开始操作。首次安装后的链接关联可能需要等待或按系统提示允许。若未打开，可回到入口页点“已安装，打开 NFC 助手”，或复制 NFC 链接手动粘贴到助手。

### 安卓手机发送名片

1. 在员工 NFC 页选择商务场景；临时展会分享可选择有效活动。
2. 点击“打开 NFC 助手”，完成联网核对后，选择开启手机模拟并确认。
3. 保持助手在前台、手机亮屏解锁，让对方手机靠近发送手机的 NFC 天线位置。天线通常在背面上部，具体位置以机型为准。
4. 接收者按系统提示打开链接。iPhone 支持后台读取的机型为 XS 及以后，通常将顶部靠近并点击通知；安卓接收机通常需要开启 NFC、亮屏解锁。
5. 每次模拟最多 5 分钟，活动分享不超过活动结束时间。离开助手、锁屏、息屏或点击结束会停止本次模拟；需要时重新开启。

助手显示“链接已被读取”只表示 NFC 读取完成，不代表对方已打开网页。名片网页、AI 对话仍需要网络。手机上的 NFC 模拟与钱包、门禁卡可能发生路由冲突；本应用无需设为默认支付工具。

### 写入 NFC 贴纸

1. 准备已格式化为 NDEF、可写的 NFC 贴纸。短链可先选 NTAG213 样品；容量较长的内容按实测考虑 NTAG215/216。贴金属或手机背面时需单独验证，必要时使用抗金属标签。
2. 在员工 NFC 页点击“写入 NFC 贴纸”，核对本人名片。进入助手后，点击“写入长期贴纸（无活动）”，确认公开名片并选择“开始等待贴纸”，再贴近标签；仅导入链接不会自动开始写入。首版只写固定名片短链 `https://haiwex.com/aicardhub/c/{code}?s=nfc`，不带展会活动参数。
3. 将贴纸贴紧安卓手机天线，查看标签原有内容、容量和待写入地址；确认后再写入。覆盖会改变贴纸内容。
4. 持续贴紧，等助手显示“写入完成”并确认回读一致后再移开。不要在写入或回读中切换页面、锁屏或移动标签。
5. 结束写入后，用安卓或 iPhone 读取贴纸，检查是否打开正确的名片，并验证“保存联系人”、联系方式等页面操作。

写入、读取、手机模拟互斥，不能同时执行。首版不支持格式化未知标签、写只读贴纸或永久锁卡。容量按实际编码后的 NDEF 字节检查；容量不足时不会截断内容。写入中断或回读失败时，内容可能已经变化，请先重新读取，再决定是否重写。

固定短链的名片资料可在后台更新，贴纸地址无需重写；**更换员工需要重写贴纸**。当前不支持逐张贴纸挂失或后台换绑，员工停用会关闭对应员工名片。关闭本机 NFC 模拟不会撤销已被他人读取的公开网址。

### 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 微信中打不开助手或安装包 | 点右上角菜单，在系统浏览器打开；不要连续点击造成重复跳转 |
| 手机 NFC 按钮不可用 | 用安卓浏览器打开线上 HTTPS 页面；浏览器只选择指引，实际硬件支持由助手检查 |
| 已安装但点链接仍在网页 | 在帮助页点“已安装，打开 NFC 助手”，检查系统“默认打开/打开支持的链接”，或复制完整 NFC 链接到助手 |
| 接收手机没有反应 | 检查 NFC、屏幕与解锁状态，移动到天线位置，先取下厚壳/磁吸配件，排查钱包或其他 HCE 应用冲突 |
| iPhone 不能发送或写贴纸 | 本期 iPhone 仅接收；发送可用二维码或链接，贴纸由安卓助手写入 |
| 无 NFC 或不支持 HCE | 不支持 HCE 的安卓仍可能支持贴纸读写；按助手检测结果操作，无法使用时改用二维码/链接 |
| 标签只读、非 NDEF 或容量不足 | 换用可写且已 NDEF 格式化的标签，检查实际容量；不尝试解除永久只读锁 |
| 活动链接已失效 | 用页面的“打开普通名片”；长期贴纸始终使用无活动的固定链接 |
| 仍看到旧版页面 | 刷新或关闭旧标签页，从上述 HTTPS 地址重新打开；如页面被缓存，再清理该站点缓存 |

`127.0.0.1` 只代表当前设备，不能写入给别人的 NFC 标签。手机验收使用线上 HTTPS 域名。应分别测试“手机 → 安卓/iPhone”“写贴纸 → 回读”“贴纸 → 安卓/iPhone”；网页模拟和单元测试不替代射频验收。

开发构建、签名和许可证见 [安卓助手 README](apps/nfc-android/README.md)；发布记录见 [HTTPS 部署验收](tasks/reports/nfc/https-deployment.md)；采购与批次验收见 [贴纸写入与采购验收](tasks/nfc/贴纸写入与采购验收.md)。

## 本地运行

运行环境：Windows、Python3.12、uv、Node≥22.23、pnpm（各应用packageManager指定版本）、MySQL8。

1. 按`server/.env.example`准备`server/.env`，设置独立项目数据库与JWT密钥。测试使用独立数据库。
2. 在仓库根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start-local.ps1
```

3. 打开访客名片`http://127.0.0.1:5173/card/demo`、员工登录`http://127.0.0.1:5173/login`和管理后台`http://127.0.0.1:5174`。

演示账号在本机`server/local-credentials.json`。日志在`.local/`。详细操作见[本地验收操作](docs/本地验收操作.md)。


检查结果以`tasks/reports/`实际报告为准。启动脚本与检查脚本不代表功能已验收。测试模型使用FakeLLM；真实模型与正式知识评测单独记录。

## 工程结构

- `server/`：FastAPI、Pydantic2、SQLAlchemy2异步、Alembic、MySQL8。
- `apps/h5/`：基于vue3-vant-mobile的访客与员工端。
- `apps/admin/`：基于pure-admin-thin的ElementPlus后台。
- `apps/nfc-android/`：Kotlin 安卓 NFC 助手，手机发送、标签读取与贴纸写入。
- `contracts/`：实现契约与生成的OpenAPI；前端从OpenAPI生成客户端。
- `e2e/`、`loadtest/`：独立本地API、浏览器与并发验收。
- `docs/`：需求、原型、工程框架及已批准的需求裁决。
- `tasks/`：原计划、执行看板、真实验证报告。

两个前端独立安装和锁依赖，不建立pnpm workspace。开发者先阅读`AGENTS.md`与子目录规则。任务使用独立worktree，共享迁移与接口有唯一所有者。
